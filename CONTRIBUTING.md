# Contributing

1. Pick a clear issue or create one with context.
2. Fork/branch from `main`.
3. Make a focused change.
4. Run `npm run typecheck` and `npm run build`.
5. Open a pull request with a concise description and screenshots when useful.
6. Respond to review comments and update documentation when the architecture changes.

## Content rules

Do not invent chapter members, awards, event attendance, project deployment claims, or institutional approvals. Sensitive systems such as attendance, identity, security, and hostel workflows must document authorization, privacy, and auditability.
