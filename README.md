# ACM BIT Mesra

**BUILD. LEARN. SHIP.**

Production-oriented ACM Student Chapter platform for Birla Institute of Technology, Mesra.

## Live site

GitHub Pages: `https://sh20raj.github.io/acm-bitmesra.github.io/`

## Stack

- Next.js App Router
- TypeScript
- React
- Custom CSS design system
- Static export for GitHub Pages
- GitHub Actions

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run typecheck
npm run build
```

## Content

Update `data/content.ts`. Keep UI components data-driven and verify real-world claims before publishing them.
