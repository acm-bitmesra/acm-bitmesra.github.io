# Project Context

ACM BIT Mesra is positioned as a long-term digital infrastructure platform rather than a generic college-club microsite.

## Product goals
- Help students discover projects, events, communities, research, resources, and contribution paths.
- Make useful technology visible and reusable across batches.
- Keep unverified facts clearly marked or omitted.
- Create a clean foundation for future backend modules.

## Current scope
The current site is static and GitHub Pages compatible. Project, event, article, SIG, resource, achievement, and gallery content is data-driven in `data/content.ts`.
