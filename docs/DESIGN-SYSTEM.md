# Design System

## Palette
- Background: `#080808`
- Surface: `#101010`
- Text: `#F4F4F1`
- Muted: `#929292`
- Border: `#272727`
- Accent: `#E31B23`

## Typography
Primary: system UI stack compatible with Inter/Geist. Technical labels: system monospace.

## Principles
- Editorial hierarchy.
- Minimal gradients.
- Strong whitespace.
- Subtle borders.
- Reduced motion support.
- Keyboard-visible focus states.
- Avoid generic glassmorphism and noisy 3D effects.
